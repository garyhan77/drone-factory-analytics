# Drone Factory Analytics

Analytics over **synthetic** drone-factory data: work orders, inspections, parts inventory, receiving, shipping and
lot traceability, stored in PostgreSQL, checked with SQL data quality tests, and shown in a Streamlit app.

**Live app: https://drone-factory-analytics.streamlit.app/**

All data is generated by this repo. It is not real company data. The full design is in [DOMAIN.md](DOMAIN.md).

*(A fuller write-up, in my own words, comes in Phase 7.)*

## Run it locally

```
make setup                # virtual environment and dependencies
cp .env.example .env      # then fill in DATABASE_URL (and TEST_DATABASE_URL for the tests)
make build                # generate the data, load PostgreSQL, build the views, run the data quality checks
make run                  # open the app
make test
```

Hosting the app online: see [HOSTING.md](HOSTING.md).
